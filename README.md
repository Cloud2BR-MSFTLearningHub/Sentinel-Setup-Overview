Microsoft Sentinel is Microsoft's cloud-native SIEM and SOAR platform. This
repository explains how to design, deploy, validate, and operate Sentinel across
Azure, Microsoft security services, and third-party data sources.

## Start Here

- [Documentation hub](docs/index.md)
- [Sentinel overview](docs/00-overview.md)
- [Deployment checklist](docs/operations/deployment-checklist.md)
- [Microsoft Sentinel documentation](https://learn.microsoft.com/en-us/azure/sentinel/)

## Scope

These guides are learning material and deployment references. Confirm current
product support, licensing, regional availability, and security requirements in
Microsoft's official documentation before production rollout. For official
guidance or support, contact Microsoft directly.
